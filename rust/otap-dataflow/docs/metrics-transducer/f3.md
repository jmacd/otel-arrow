# F3. Conformance, resource limits and operations

[Worklist](../metrics-transducer-worklist.md) | [Fixture contract](a3.md) |
[Regional demonstration](f2.md)

The release evidence is a corpus of timestamped inputs with independent
expected answers, plus an operator runbook. Reuse those inputs for direct,
replayed and staged execution. Mark each fixture with its permitted
topologies and representations: a Prometheus scrape cannot expose internal
deduplication state, and an ordinary OTLP peer cannot interpret revisions.

## Minimum conformance matrix

| Fixture or fault | Observable assertion |
| --- | --- |
| Unknown start `900 -> 907`, true reset and a signed `7 -> 4` in an unbroken epoch | First unknown sample is a baseline; the three cases yield increase 7, a new input epoch, and signed change -3, respectively. |
| Gauge populations `{2,4,6}` and `{12}`; different histogram layouts | Combined mean is `24/4 = 6`, not `(4+12)/2 = 8`. Compatible bucket merges preserve counts; incompatible layouts yield the documented diagnostic. |
| No-data marker, then late history for a retired series | An eligible historical cell can change under its declared policy; the retired series does not become live. |
| Revision 2 seals with correction `+8` before revision 1 (`+90`) arrives | No complete value of 8. After both arrive, the complete value is 98. Retry, restart and delivery order leave it unchanged. |
| Read snapshot P, publish P+1 during the handoff, then follow | A valid cursor observes P+1 exactly once logically. An expired cursor yields an explicit gap. |
| Crash on each side of the checkpoint commit, raw input at its disk limit, link disconnected | Readers see an old or a new complete commit. Reserved checkpoint space permits progress at the configured cap; physical storage failure is visible. |
| Query and fixed rule over the F1 count fixture, then input spanning a required pane | Supported equivalent rules produce 7. Exact interval mode reports the straddling contribution instead of silently assigning it by end time. |

Drive the clock, seal requests, fault triggers, durable barriers and ACKs from
the fixture. Wait on those events rather than sleeping. Compare numeric output
*and* descriptors, epochs, completeness, progress, duplicate suppression and
the ability to continue after clearing a fault. For optional features add
[gauge histogram](c4.md) and [sampling](g4.md) cases to the same cuts.

## Capacity and operational evidence

For a declared input rate, series population and retention configuration,
record resident bytes, raw and checkpoint bytes (including temporary
commit space), replay duration, commit latency, bookmark and reader lag.
Increase cardinality, fill storage and stall progress independently. Verify
the configured bounds and account for refusals, late rejections, duplicates
and overflows. Do not treat legitimate UDP loss as an accepted contribution
or count a local socket send as a remote durable ACK.

Ship the enabled node/codec inventory, feature gates, supported platforms,
example limits and operator actions. In particular: distinguish a lagging
reader that can resume, an expired cursor requiring explicit resynchronization
and a corrupt required checkpoint that must stop recovery. The runbook must
identify the affected writer and position without exposing raw attributes
as diagnostic metric labels. Publish observable changes with the components'
changelog entries when the implementation ships.
