# G1. Estimate contributions from discarded dimensions

[Worklist](../metrics-transducer-worklist.md) | [Verification](g4.md)

After projecting `host` out of a service counter, how much of its increase
came from a given set of hosts? Sample **series**, not measurements or
traces. This design applies to additive Counter and UpDownCounter changes.
A rule can enable G1, [trace drill-down](g2.md), both, or neither. The
recorded metric, including its start time and value, must be identical.

## One item per original series

For each projected group and aligned interval `(start, end]`, first resolve
accepted inputs at full identity: resource/entity, scope, metric descriptor,
typed point attributes and logical writer (A1). Use C1's reset-aware deltas:
an unknown first cumulative value establishes a baseline, not an increase;
a change from 7 to 4 in one UpDownCounter epoch contributes -3. A no-data
marker is not a measurement. Sum resolved changes per identity, across any
resolved epoch breaks, **before** projecting or ranking. One hundred reports
from one series still make one item, even if none carried an exemplar.

For item `i` let `v_i` be that signed interval sum, `w_i = abs(v_i)` its
selection weight. The exact metric delta is `D = sum(v_i)`. The optional
exact total selection weight is `W = sum(w_i)`, not `abs(D)`. Compute the
magnitude after summation; `+4,-4` contributes zero, not weight 8. Omit
zero-weight items: they cannot change any **sum** estimate. This sample
cannot estimate their count. Reject unsupported/non-finite weights or
arithmetic overflow as a sampling error; never coerce them into ranks.

## Rank law and subset estimate

Use the exponential-rank design of [Cohen and Kaplan][bottom-k]. Draw
independent `U_i ~ Uniform(0,1)` for distinct full series identities, once
per compatible sampling generation. Keep each draw stable across panes,
revisions, replay and partitions: derive it from a common persisted seed,
sampling domain and canonical series key, not arrival order, window, value,
trace ID or the projected group. The statistical model treats the draws as
independent of the inputs and the subset predicate.

1. Compute `r_i = -ln(U_i) / w_i` for positive weights. Keep the `k >= 1`
   smallest ranks and `tau`, the first excluded rank (the `(k+1)`st). A
   bounded max-heap suffices when feeding finalized per-series items. If
   there are at most `k`, set `tau = infinity`; empty is a valid result.
2. Store each winner's series key, allowed dimensions, original signed
   value, weight and rank, **not** an adjusted value masquerading as an
   observation. This is a series-derived interval exemplar, not an OTLP
   measurement; it has no fabricated measurement timestamp or trace link.
3. For a fixed predicate `P` on retained dimensions, sum `v_i / p_i` over
   matching winners. Conditional on all **other** ranks, inclusion means
   beating their `k`th rank. For a winner this threshold is exactly `tau`,
   so `p_i = 1 - exp(-w_i * tau)` (`1` in keep-all). Use `-expm1` for
   small arguments. Nonwinners contribute zero. This rank-conditioned
   estimate has expectation `sum(v_i where P(i))` under the stated law;
   it is not exact on a particular draw. Reject unsupported predicates.

For example, one UpDownCounter has hosts A, B, C with `v = (+8,-2,+1)`
and draws `U = (1/4,1/2,1/2)`. In units of `ln(2)` their ranks are
`(1/4,1/2,1)`. With `k = 2`, `tau = ln(2)` and B's estimated change is
`-2 / (1 - 1/4) = -8/3`, not +2. The exact group change is +7, and
`W = 11`. With `k = 3`, B must return exactly -2.

## Scope and implementation decisions

The continuous law has no ties almost surely. A deployed rank format must
version its seed derivation, numeric precision, comparison and stable tie
key; arrival order is not a tie break. A finite grid with ties does not
have the continuous CDF above. Require its own inclusion law (including
ties and positive inclusion chances) or label its estimates approximate.
The portable numeric profile is open, not permission to mix rank laws.

Gauges describe a population at a boundary, not additive changes. Reject
this mode for gauges. A separate policy could sample one last live reading
per series with unit weight and estimate a population sum and count; it
would need its own staleness and mean contract. Do not rank gauge values,
histogram buckets or trace measurements by `abs(value)` under this rule.
