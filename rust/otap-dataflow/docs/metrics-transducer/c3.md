# C3. Select gauge populations and merge histogram intervals

[Worklist](../metrics-transducer-worklist.md)

## A gauge has one vote at a boundary

For boundary `b` and rule lookback `H`, select each contributor's last
observation in `(b-H,b]` (default `H` is five minutes in the
[query RFC][rfc]). A no-data marker in that position suppresses the series;
never search past it for a value. Break equal event times by the persisted
input position and point ordinal, greatest last. Replay uses the same keys;
conflicting payloads under one publication ID are errors, not ties.

For a spatial mean, project only after selection. Each live value `v`
supplies `(v,1)`. Add sums and population counts across disjoint writers at
the **same boundary**; divide once, after merging. An empty population gives
no value. If one edge has values 2, 4, 6 and another has 20, partials
`(12,3)` and `(20,1)` give 8, not the mean of edge means, 12. Send these
partials to a capable next stage, not just finalized averages. At its next
boundary an unchanged population is still `(32,4)`, not `(64,8)`. Adding
observations over time answers a different query.

## An ordinary histogram counts measurements in intervals

Bind a target layout for the rule generation. Normalize to it before
differencing adjacent cumulative points per writer under [C1](c1.md), or
consume the whole delta directly. Add disjoint intervals over time and
disjoint populations over space. Count and every bucket must have
nonnegative integer deltas; buckets must total count. For bounds `[5,10]`,
cumulative buckets `[2,1,1]` then `[3,3,1]` give delta `[1,2,0]`, count 3.
Coarsening to `[10]` gives `[3,0]`; the count stays 3.

- Explicit bounds must increase strictly; counts have one extra overflow
  bucket. Coarsen only to a subset of source bounds, summing whole adjacent
  buckets. A count-only distribution cannot satisfy a bucketed rule.
- For exponential buckets take signed index `i = offset + position` on each
  sign separately. To lower scale by `d`, add to `floor(i / 2^d)` at the
  target scale; align offsets and add zero counts separately. In v0 require
  equal zero thresholds. Reject upscaling, bucket splits, cross-family
  conversions, oversized layouts and arithmetic overflow; report the reason.
- Difference an optional sum only when both sums exist; merge sums only
  when known throughout. Absence is not zero. Combine available interval
  extrema by min or max only when every nonempty part supplies that field.
  A first known-zero interval can retain its extrema; for differences of
  lifetime snapshots omit extrema. Subtracting cumulative minima or maxima
  cannot recover interval extrema.

Use the existing [metric views][views] and [record builders][builders] for
I/O. The transducer needs new last-per-contributor and histogram partials;
the temporal processor's latest row does not implement these merges. Report
and exclude a valued gauge missing its number, a histogram lacking
temporality, or a Summary: reported quantiles cannot be merged as
measurements. Pass input exemplars to the bounded G sampler with original
value, time, filtered attributes and trace/span IDs before projection. They
are not measurements to add again.
