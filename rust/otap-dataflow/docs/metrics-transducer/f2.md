# F2. Regional forwarding and equivalence

[Worklist](../metrics-transducer-worklist.md) | [Local example](f1.md) |
[OTAP publication contract](e4.md)

Show that regional aggregation yields the same answer as the direct calculation
after a link outage. The two paths must see the **same accepted datagrams**;
sending duplicate UDP traffic to a reference process gives it different ingress
timestamps and potentially different losses.

## Topology and comparison point

Each edge owns its raw store, checkpoint store and one-minute rule. Attach a
local cumulative reader and a durable delta reader to the same commits. The
latter uses the [OTAP exporter][otap] and an OTAP receiver at B. B owns a
separate namespace, ports and cursors. It combines sealed deltas on an
aligned five-minute grid. Project away `host` at the edges but retain edge
writer and generation for delivery and deduplication, outside the reported
service labels.

Identify a comparison by the five-minute boundary **and** each required
writer's durable publication position. Hand-calculate the reference from the
accepted edge fixtures ([A3](a3.md)). Wait for B's commit covering those
positions. Align output epoch starts before comparing cumulative values;
different generations or an incomplete cutoff are observable conditions, not
evidence of an arithmetic error.

## Failure script

| Action within `(10:00, 10:05]` | Required outcome |
| --- | --- |
| Disconnect before edge west publishes a minute containing `3 + 4` | West still seals and its local cumulative reader returns 7. Its push cursor remains behind. |
| Keep the outage within retention; east independently publishes 5 for the same service | B can see east's progress but cannot yet report the five-minute window as complete. |
| Reconnect west. Let B make west's `+7` durable; drop the ACK before west receives it | West retries the same publication, even on a different gRPC stream. B recognizes it and acknowledges it without adding it again. |
| Deliver all required positions, including progress for empty minutes | At the common cut B reports 12 for `service=api`, equal to the direct `7 + 5`. An additional scrape or retry still returns 12. |

Restart B just after durable acceptance in the lost-ACK case; restart the
sender before recording the ACK in another run. Neither restart may assign a
new identity to the retried `+7`. The existing stream batch identifier
correlates an attempt; it cannot by itself pass this exercise.

For the equality run, do not advance the configured cutoff past the missing
writer. In a separate run, deliberately cross the cutoff or exhaust retained
history. Expect an incomplete commit or explicit reader gap as appropriate;
the system must not claim equality with the complete direct result. Document
which reader position or progress record the operator uses to distinguish
catch-up from permanent missing coverage.
