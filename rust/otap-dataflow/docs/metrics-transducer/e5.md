# E5. Refine a window without mistaking a seal for completeness

[Worklist](../metrics-transducer-worklist.md) | Depends on [E4](e4.md).

On a capable link, a cell may publish before it closes. Use the
[rule RFC][rfc] for plan classes and the [E4 publication key](e4.md) for
durable identity. Per-cell revisions are dense from 1. Phase is
`provisional`, `sealed` or `restated`. Encoding is an independent choice:
a correction carries `V(r) - V(r-1)`; a restatement carries full `V(r)`.
A sealed revision can therefore contain only an increment.

Set proposed local point mask `0x0000_0002` on every publication of a cell
that can repeat, including its first. This bit is not an assigned [OTel
point flag][flags]. It means intentional repetition, not revision, identity,
phase or completeness. Sealed-only ordinary points have the bit clear.
Negotiate the extension; placement of keys, phases, encodings and coverage
proofs is not yet a wire standard.

## Receiver and parent rules

1. Keep the newest full base at revision `b` and distinct corrections above
   `b`. Add a new correction once. A full value at `r > b` replaces the
   base and all corrections through `r`; retain corrections above `r`.
   Suppress covered retries; reject conflicting content for a retained key.
   Checkpoint bases, digests, gaps, progress and effects together. Recover
   the producer's committed revisions; never renumber on retry.
2. To certify a child window, require a **durable gap-free prefix through
   its seal**, or equivalent proof: a complete manifest with all named
   values durably present, or full values demonstrably covering every cell
   through that seal. A full restatement subsumes lower revisions for its
   cell only. A watermark, manifest with missing entries or highest
   revision seen is not proof. Include explicitly empty child windows.
3. Fix the required writers and nested windows for each parent cut. Retain
   child contributions by writer, generation, window and cell. Replace a
   restated child, do not add it again. Subtract the old partial and add the
   new for invertible aggregates; recompute min, max or last from retained
   children. For example, replacing minimum 2 by 8 when another child has
   5 changes the parent minimum to 5. A histogram bucket falling from 4 to
   3 cannot send `-1` in an unsigned bucket. Send a full histogram
   restatement, or report unsupported; never wrap or clamp.

## Worked seal and cutoff

Revision 2 (`sealed`, correction `+8`) arrives before revision 1
(`provisional`, `+90`). Stage the 8; it is not the sealed value. Even
after a crash the parent waits. When revision 1 is durable, the contiguous
prefix proves 98. Replaying either leaves 98. An unaware peer gets one
ordinary full sealed value, 98, not 8. A later accepted `+2` at revision 3
updates a capable parent to 100; withhold and count it on the unaware link.

If cutoff intervenes first, commit the parent **incomplete** with its input
cut, required set and missing child windows/count. Exclude the unresolved
child from the sealed subtotal; do not report 8 as complete or invent zero.
Propagate incompleteness. Replay honors that decision. Sealing ends ordinary
updates; `late: reject` closes the cell. With `late: restate`, only an
explicit newer revision within the retained restatement horizon can repair
it; it does not rewrite the earlier commit. At horizon expiry reject/count
late changes. Cap revisions, gaps, child values and retained bytes even if
seals stall; backpressure or expose loss, never infer completion to free RAM.
