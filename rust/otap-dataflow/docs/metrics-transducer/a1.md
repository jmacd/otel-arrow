# A1. Rule identity, time and schema

[Worklist](../metrics-transducer-worklist.md) | [Evaluation boundaries](a2.md)

A rule defines what counts as one contribution and what counts as one output.
For example, `requests` from two hosts in `service=api` should produce one
service total. The evaluator still needs both hosts' identities to recognize
resets before adding anything.

## What identifies what

| Term | Definition |
| --- | --- |
| Contributor | Logical writer and full input series: resource identity, instrumentation scope, metric descriptor and typed point attributes. A reconnect or a new Arrow batch does not create a writer. |
| Input epoch | An unbroken sequence for one contributor. A start-time change can identify a reset without changing the series key. |
| Output series | Output resource, scope, metric descriptor and retained dimensions after projection. `resource.service.name` and a point attribute of the same name are distinct keys. |
| Cell | One output series, rule generation and evaluation boundary. A publication revision addresses that cell; it is not an output label. |

Attribute ordering, Arrow dictionary indices, batch-local parent IDs and
transport request IDs must not affect identity. Preserve value type and
distinguish an absent grouping key from a present empty string. Resolve hash
collisions by equality of the underlying identities. The [existing identity
helpers][identity] illustrate the resource/scope/metric/stream hierarchy;
their in-process representation is not the checkpoint format.

## Compilation and admission

Compile the selector or [query](e6.md), output name, qualified grouping keys,
aggregation, period, origin, allowed lateness and requested representations
before accepting input. The plan declares the input kinds, numeric types,
units and histogram layouts it can combine. Binding a matching descriptor
checks those requirements; an incompatible unit or layout must produce a
diagnostic rather than extending the output under the same name. Perform
per-source [resolution](c1.md) before dropping any identity fields.

Persist a versioned description of the effective rule with the checkpoint.
Changing retained keys, units, window alignment or arithmetic changes the
meaning of old results: start a new generation or require an explicit
migration. Changing how a reader presents the same committed value does not
re-key contributors or reset another reader. Exported streams must preserve
the [single-writer contract][model], including when two edges export the same
projected labels to one region.

## Acceptance

In one window, `host=A` advances from a baseline of 900 to 907; `host=B`
advances from 10 to 13. Both have `service=api`. Grouping only by service must
produce a delta of **10**, including when batches interleave or their
attribute dictionaries differ. Switching the projection to include `host`
must not reinterpret that committed `10` as either host's prior value.
